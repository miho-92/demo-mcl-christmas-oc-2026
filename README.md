# MCL クリスマスオープンキャンパス LP

FigmaのPDF・SVGを土台に、DMとプログラム資料を統合した静的LPです。2026年11月4日、全28種類の体験授業を反映しました。

## 確認・アップロード

`index.html` をブラウザで開いて確認できます。ビルド・npmインストールは不要です。

公開先に `index.html`、`style.css`、`config.js`、`main.js`、`assets/` を同じ構成でアップロードしてください。READMEはアップロード不要です。サブディレクトリにも配置できます。全画像は同梱し、一時的なFigma URLや外部フォントには依存しません。

## 申込URL

正式な申込URLを `config.js` の `reservationUrl` とHTML内の2か所の申込ボタンに設定しています。新しいタブで申込フォームを開きます。JavaScriptが無効でもHTMLのリンクから利用できます。

申込フォーム： https://bc.linesg.jp/linebc/liff_oc/liff_oc_open.aspx?scl_no=9298900&event_id=9a3c5800-462f-490d-9fb2-13ccc0c18215&access=pc

今後変更する場合は `config.js` のURLと、HTMLの `data-apply` 属性がある2リンクを合わせて更新してください。

## 授業情報の更新

申込フォームのCSVを基本とし、2026年11月4日に確認した以下の3点はプログラム一覧PDFを優先しています。

- グラフィックデザイン「クリスマスカードを作ろう！」：60分連続・定員6名
- ホテル「フルーツカット」：60分連続・定員8名
- ライフデザイン「人生を明るく彩ろう！」：各回30分・各10名として追加

全28種類は30分22種類、60分6種類。第1回は10:50〜11:20、第2回は11:30〜12:00。60分の体験は10:50〜12:00の時間帯で第1回・第2回を通して参加します。

同じ授業の開催回は1枚のカードにまとめています。すべての分野名を「○○分野」に統一し、カード内で最も大きく表示しています。内容、定員、担当校を掲載し、体験時間は補足情報として控えめに表示。CSVにある正式な学科・専攻名は担当欄に補足し、合同授業の学科は連名です。持ち物と服装の案内も掲載しています。

今回の見直しで「体験の選び方」の説明ブロック、授業カードの開催回・時間帯、体験時間フィルターを削除しました。詳細は申込フォームで確認する案内に変更し、絞り込みは分野のみです。

「31学科・コース」の案内は今回の授業一覧に合わせ「全28種類の体験」に更新しました。動物POPの説明はCSVが空欄のため一覧PDFを使用しています。明らかな文字誤り（インテイリア→インテリア、韓国の冬の分野→文化、ゲーム開発実験→体験）は掲載用に整えています。

### 申込フォーム側の修正点

LPのみ更新しています。フォーム本体と元CSVは変更していません。公開前に以下の登録修正が必要です。

1. グラフィックデザイン：各回30分の2枠から、60分連続の1枠へ変更
2. ホテル：各回30分の2枠から、60分連続の1枠へ変更
3. ライフデザイン：第1回・第2回の各30分、定員各10名で追加

LPにリアルタイムの残席は表示せず、「各体験は定員になり次第、受付終了」と案内しています。

## その他の公開前確認

- 受付時間：FigmaとDM中面に合わせ10:00を採用。DM表面は10:15のため主催者確認が必要です。
- 友達参加特典：Figmaにある「12/26（金）」は2026年の曜日と不一致のため、送付日を保留。確定日を追記してください。
- 菜園調理系の学校名と2027年4月の名称変更注記は最終確認してください。
- バス案内は往路時刻と帰路14:00出発を掲載。各停留所の帰路到着時刻は省略しています。
- フッターは提供SVGのグループ一覧です（釜石市国際外語大学校を含む）。

## 素材と機能

共有されたSVG8点と、追加で支給されたランチ・景品のPNG画像を使用。元の共有ファイルは変更していません。

- 分野による絞り込み、件数表示、該当なし案内
- 固定ナビ（開催概要・特典・体験内容・バス・申込）、現在位置の表示
- PCの両側写真を固定し、中央カラムをスクロール
- 無料送迎バス8ルートの開閉
- 正式申込フォームへのリンク、キーボード操作・フォーカス表示
- スマートフォン対応、動きを減らす設定に対応

## 今回の確認

全28カードの分野名、内容、体験時間、定員、担当校の保持と、削除対象（選び方ブロック・開催回・時間帯・体験時間フィルター）が残っていないことを検証。ブラウザで動物分野4件、すべて28件への復帰を確認。375px・320px幅で分野名の強調と横はみ出しなしを確認しました。JavaScript構文も確認済みです。

## 構成・ナビの見直し

開催概要の本文を基本15px、開催時間を23px、学校一覧を13pxに拡大（320px幅では一部を調整）。白いパネルは内容に応じて高さが伸びる構成です。

参加特典とお楽しみを同じセクションに統合し、「友達参加特典→事前予約特典→ランチ・抽選会→体験授業→バス」の順に変更しました。当日の流れは「1日で最大2つの分野が体験できる」紹介の直後へ移動しています。特典カードの余白も縮めました。

画面下に5項目の固定ナビを設置し、現在位置を強調します。最下部にはナビと重ならずスクロールできる余白を確保しています。画像はスクロールに追従せず固定表示する背景に変更しました。

ブラウザで固定背景・固定ナビのスタイル、特典の順序、体験・バス・申込へのリンク移動を確認しています。28授業の掲載情報を再検証し、ZIPを更新しています。

## 余白と情報表示の調整

開催時間を29px（320px幅では27px）に拡大し、住所とアクセスリンクの余白を10pxへ縮小。開催校一覧は中央揃えです。

紹介セクションの固定高さを解除し、写真のサイズと下余白を調整。直後に当日の流れを置き、その後に特典・お楽しみが続きます。

授業カードの体験時間と定員を横並びの小さな情報欄にまとめ、区切り線と上下余白を削減しました。28授業の内容・分野・定員は保持しています。今回の変更は構造とローカル参照・JavaScript構文を検証しました。ローカルファイルを直接開くブラウザ検証は環境のURL制限で実施できていません。

## 体験一覧のデザイン変更

体験一覧を、生成りの紙面に細い罫線で並べるプログラム冊子風の表示へ変更しました。丸いカードと色付きの囲みを外し、通し番号01〜28と分野名を大きく表示。体験時間・定員は小さな横並び、担当校は末尾の補足情報にしています。絞り込みも丸いボタンから文字と下線の表示へ変更しています。全28授業と分野別絞り込みを保持しています。

ブラウザで375pxの実表示と320px幅のはみ出しなし、動物4件・全28件への絞り込み復帰を確認しました。

## DMに合わせた体験一覧

体験一覧を、緑の模様背景に白い紙面を並べる囲みへ変更しました。元のDMを踏まえ、分野名を赤い紙ラベルで表示し、分野名・体験タイトル・説明文の文字の太さを800・600・400に分けています。体験時間と定員は小さな横並び、担当校は末尾の補足情報です。大きな「28」と英語の飾り見出し、通し番号は削除しています。

375pxの実表示、320px幅のはみ出しなし、動物分野4件と全28件への復帰を確認しました。

## 原稿と申込フォームの最終調整

依頼された受付・スケジュール・特典・バスの文言を反映し、不要な補足文と英語ラベルを削除。受付削除文の分はタイムラインの行間を調整しています。分野フィルターは白い2列ボタンで表示し、選択中は赤色とチェックで明示します。長い分野名は意味のまとまりで改行しています。

全28授業のタイトルに語句単位の改行候補を設定し、タイトルの途中で不自然に分割されるのを抑えました。320px・375px幅でのはみ出しと文字サイズ、動物4件・全28件への絞り込み復帰、2か所の正式URL・新規タブ設定を検証しました。実際の申込操作やフォーム登録変更は行っていません。

## クリスマスの動き

ヒーローに小さな星6個のきらめきと中央の星の光、申込ボタンに約7秒周期の光の演出を追加しました。カード・特典・写真は画面に入ると一度だけ短くフェードしながら現れます。本文はCSSで非表示にせず、JavaScriptやアニメーション非対応時も読むことができます。

端末の `prefers-reduced-motion` が有効な場合は装飾の繰り返しアニメーションを停止し、カードの登場演出も行いません。設定変更時は実行中の登場演出を中止します。装飾はクリックや読み上げの対象外です。

ブラウザで星・光のアニメーション設定、375px/320px幅、分野絞り込み4件/全28件への復帰、本文が表示されたままであることを確認しました。JavaScript構文と画像参照も検証しています。

## 支給写真への差し替え・きらめき調整

`LP素材-21.png` をランチBOXの写真として `assets/lunch-photo.png` に、`LP素材-20.png` を景品画像として `assets/prizes.png` に同梱しました。角丸加工済みの22番ではなく、余白のない21番を使用し、LPの既存の囲みに合わせています。元画像の内容を変更せず、全体が見える縦横比で表示しています。旧PDF切り出し画像は使用していません。

ヒーローの星を6個から10個へ増やし、サイズを約12〜20px、明るくなる周期を約3.3秒に変更。中央の光も大きくし、参加特典と体験紹介の見出しに小さなきらめきを追加しました。動きを減らす設定は引き続き優先します。

375px/320px幅で画像読み込み・全体表示・横はみ出しなしを確認しました。

## きらめき演出の取り消し

追加した星の装飾、中央の光、見出しのきらめき、申込ボタンの光を取り消しました。元画像の星と模様はそのまま使用しています。スクロール時の一度だけの登場演出と、ボタンを押したときの反応は残しています。
